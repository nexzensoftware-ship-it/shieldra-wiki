# Shieldra — Dashboard UI Kit

Product dashboard recreation. Collapsible sidebar, top header with breadcrumbs + AI assistant, compliance score gauge, stat cards, findings table, framework progress.

## Components
- `Sidebar.jsx` — grouped navigation with icons (Dashboard, Compliance, Risk & Security, AI & Intelligence, Evidence)
- `Header.jsx` — breadcrumb + search + bell + user menu + AI-assistant pill
- `ScoreGauge.jsx` — circular compliance score (score-gauge.tsx port)
- `StatCard.jsx` — KPI tile with eyebrow, icon, value, delta
- `FindingsTable.jsx` — severity-colored rows with framework tags
- `FrameworkProgress.jsx` — bar list showing HIPAA / SOC 2 / ISO / PCI / GDPR progress
